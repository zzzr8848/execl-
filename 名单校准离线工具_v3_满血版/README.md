
# Excel 名单校准离线工具 v3 满血版

这是一个完全离线的小工具，用于把“新名单”按“源名单”的顺序自动校准，并输出适合政务/办公核对的完整结果。

## v3 满血版新增功能

1. **自动改名保存**
   - 若目标结果文件正在被 Excel/WPS 占用，程序会自动尝试保存为：
   - `名单校准结果_v3_1.xlsx`
   - `名单校准结果_v3_2.xlsx`
   - ...

2. **二级匹配键**
   - 支持设置主键列 + 辅键列
   - 典型用法：
     - 主键：姓名
     - 辅键：电话后4位 / 身份证后4位 / 年龄 / 村社区 / 住址片段
   - 内置 3 种匹配模式：
     - 仅主键精确匹配
     - 主键+辅键联合精确匹配
     - 优先联合匹配，必要时回退主键

3. **疑似匹配建议**
   - 对未匹配成功的记录，自动生成“疑似匹配建议”工作表
   - 仅供人工复核，不会自动合并

4. **更适合办公审查的输出**
   - 汇总统计
   - 状态高亮
   - 冻结首行
   - 自动筛选
   - 重复检查
   - 源名单缺漏
   - 新名单多出

## 输出工作表

- `汇总`
- `按源名单顺序校准`
- `源名单缺漏`
- `新名单多出`
- `重复检查`
- `疑似匹配建议`
- `说明`

## 建议使用方式

### 普通名单核对
- 主键：姓名
- 匹配模式：优先联合匹配，必要时回退主键
- 辅键：可不设置

### 重名较多
- 主键：姓名
- 辅键：电话后4位 / 身份证后4位 / 年龄 / 村社区
- 匹配模式：主键+辅键联合精确匹配

## 运行方式（Anaconda + PyCharm）

### 1）创建环境
```bash
conda create -n name_align python=3.10 -y
conda activate name_align
pip install openpyxl
```

### 2）在 PyCharm 中运行
- 用 PyCharm 打开本文件夹
- 解释器选择你的 conda 环境 `name_align`
- 直接运行 `excel_name_align_tool_v3.py`

### 3）打包成 exe
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name 名单校准工具_v3 excel_name_align_tool_v3.py
```

打包完成后，exe 在：
`dist/名单校准工具_v3.exe`

## 注意事项
- 支持 `.xlsx` / `.xlsm`
- 老版 `.xls` 请先另存为 `.xlsx`
- 全程离线，不上传任何数据
